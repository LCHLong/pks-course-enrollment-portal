# PKS Course & Enrollment Portal

Mini web-app phục vụ tra cứu, quản lý và ghi danh các khóa học công nghệ.
Bài test kỹ năng Vòng 2 - Thực tập sinh Fullstack Developer (Node.js + React.js) - PKS.
